Is the bolt machine still making good bolts?

A factory makes metal bolts. Each bolt should be 50 mm wide. Machines slowly drift (the tool wears out, the temperature changes). If nobody notices, the factory makes thousands of bad bolts.

Our tool: every few minutes a worker measures 5 bolts (one subgroup). The tool saves them in a database, compares them with what normal looks like, and raises an alarm the moment something really changes.

Step 2: learn what normal looks like

First we run the machine when we know it is fine and take 25 subgroups. From them we calculate three lines: the centre line and the upper and lower control limits.

49.91 mm
Centre line (CL): average of the 25 averages
52.04 mm
Upper limit (UCL) = CL + 0.577 × R-bar
47.78 mm
Lower limit (LCL) = CL − 0.577 × R-bar

R-bar (average range) = 3.70 mm. 0.577 is a fixed number from the standard control-chart table for subgroups of 5.

Why the average of 5 bolts? (Central Limit Theorem)

The average of 5 bolts moves much less than one bolt (spread ÷ √5) and forms a bell curve. In a bell curve 99.73% of values sit within 3 sigma of the centre, so only 0.27% of normal points cross the limits by luck.

Say this: We collected 25 good subgroups and computed the centre line and the 3-sigma limits. Because we chart averages of 5, the Central Limit Theorem makes them bell-shaped, so a point outside the limits is very unlikely unless something really changed.

Step 3: watch the average and the spread

1.00 σ
  • X-bar chart (top) watches the average: has the machine shifted?
  • R chart (bottom) watches the spread: has the machine become shaky?
  • A point turns red when a run rule fires:
    • R1: one point outside the 3-sigma limits.
    • R2: 2 of the last 3 points beyond 2 sigma on the same side.
    • R3: 8 points in a row on the same side of the centre line.

R2 and R3 can turn a point red even when it is inside the limits: they catch patterns, not just single extreme points.

Say this: The X-bar chart checks if the average moved; the R chart checks if the spread grew. Run rules catch patterns, like 8 points in a row above the centre, which is why some red points are inside the limits.

Step 4: CUSUM catches small drifts

0.30 σ
CUSUM first alarm
3-sigma rule first alarm

Idea: instead of judging each point alone, CUSUM keeps a running total of how far each average is above (or below) normal. Tiny shifts add up, and when the total passes 5 we raise the alarm.

Each step it adds the new deviation minus a small allowance k = 0.5, so normal noise does not build up, and it never goes below 0.

Like a bank balance: one small withdrawal is not worrying, but if it keeps dropping a little every day, you notice.

Say this: The X-bar chart is good for big jumps but slow for small drifts. CUSUM adds up small deviations over time, so a small drift is caught much sooner.

B. Average run length (ARL)

ARL = how many subgroups go by, on average, before an alarm (5,000 simulated runs each). With no drift we want it big (few false alarms). With a drift we want it small (caught fast).

Say this: Theory says 3-sigma limits give 0.27% false alarms, and our simulation gave exactly 0.27%. The X-bar run lengths match the formula. For a small 0.5 SE drift, CUSUM needed about 39 subgroups and X-bar about 156, so CUSUM is about 4 times faster.
